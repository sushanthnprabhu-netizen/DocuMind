# DocuMind

**AI-powered document intelligence with a local, retrieval-augmented question-answering pipeline.**

DocuMind is a full-stack web application where users create an account, upload documents, and ask natural-language questions about their content. Document metadata, users, sessions, and extracted document chunks are stored in **Supabase PostgreSQL**. Answers are generated using TF-IDF retrieval, FAISS vector search, and a locally running Llama 3.2 model served by Ollama, so no cloud LLM API key is required.

## Features

### Document Workspace

- Upload, list, download, and delete documents from the web dashboard
- Per-user document access
- Supported formats: PDF, DOCX, XLSX, TXT, Markdown, CSV, JSON
- Document metadata stored in Supabase PostgreSQL
- Extracted document chunks stored in Supabase PostgreSQL

### Retrieval-Augmented Question Answering

- Text extraction, recursive chunking, TF-IDF vectorization, and FAISS similarity search
- Similarity threshold to avoid answering from irrelevant chunks
- Answers generated by a local LLM from retrieved context
- Source attribution with filename and match score
- Workspace questions such as "how many documents do I have?" are answered directly from the database

### Authentication

- Email and password registration and login
- Passwords hashed with salted PBKDF2-SHA256
- Server-side sessions using bearer tokens
- User and session data stored in Supabase PostgreSQL
- CORS configured for the frontend origin

### Local-First AI

- TF-IDF vectorization and FAISS retrieval run locally
- Llama 3.2 runs locally through Ollama
- No external LLM API key is required
- Document content used for generation stays within the local application and Ollama environment

### Cloud Database

- Supabase PostgreSQL stores application data
- Users, sessions, documents, and document chunks are persisted in the cloud database
- PostgreSQL foreign keys maintain relationships between users, documents, and chunks
- Document chunks use cascading deletion when their parent document is deleted
